# pcb-lab

PCBs designed entirely as code (atopile + KiCad 10 + Python), checked automatically,
reviewed through renders, and ordered assembled from JLCPCB.

- Agents: start at `CLAUDE.md`.
- Humans: review packets appear in `boards/<name>/build/review/` at each gate (`docs/review-gates.md`).
- Status: scaffold. Phase 0 (prove the pipeline) is next, see `docs/pipeline.md`.
